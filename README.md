# Редизайн магазина научных сувениров

Интерактивный документ о концепции торгового оборудования магазина музея «Экспериментаниум».
Концепция для обсуждения, не рабочие чертежи.

Адрес: https://mmshatina-afk.github.io/experimentanium-shop/

## Состав
- `index.html` — страница и блок данных `window.DATA` (варианты, комментарии на картинках, пункты листа решений, версия документа).
- `assets/site.js` — логика страницы.
- `assets/site.css` — оформление и печать.
- `assets/img/` — фото и иллюстрации.
- `assets/fonts/` — шрифт Inter.

## Как обновить сайт
Заменить в репозитории `index.html`, `assets/site.js`, `assets/site.css`. Папки `img` и `fonts` менять не нужно, если не добавлялись картинки.
Сайт публикуется из ветки `gh-pages`.

## Отметки
Хранятся только в браузере (ключ `exp-shop-site-v2`). Отметки прежней версии (`exp-shop-site-v1`) переносятся автоматически, старый ключ не удаляется.
